# Controlled Program Synthesis

This repository is an early bootstrap workspace for a SWI-Prolog research and
development project: a proof-oriented controlled-English program synthesizer.

The planned system will parse a strictly controlled subset of English into a
typed specification IR, refine it through explicit proof and pattern rules, and
render deterministic pseudocode only after independent verification.

## Current State

The project currently contains a Phase 0 bootstrap prompt under `bootstrap/`.
That prompt describes the intended infrastructure scaffold, source handling
rules, quality gate, and first implementation boundary.

## Local Sources

The `references/` directory is reserved for local primary source files used by
the bootstrap workflow. Those files are intentionally not tracked by Git in this
public-ready setup until repository visibility and redistribution rights are
confirmed.
